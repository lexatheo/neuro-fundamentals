# neuro-fundamentals

A collection of small computational neuroscience projects: building core models
from scratch in Python to understand how neurons compute.

## Projects

### Leaky Integrate-and-Fire Neuron (`lif_neuron.ipynb`)
A minimal model of how a neuron turns input into spikes. Simulates a single neuron's
membrane voltage over time (the integrate–fire–reset "sawtooth"), then a population of
20 neurons with increasing input current, visualized as a spike raster showing how
firing rate scales with input.

## Tools
Python, NumPy, Matplotlib.
